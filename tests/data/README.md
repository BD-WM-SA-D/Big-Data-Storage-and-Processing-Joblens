# Dữ liệu kiểm thử

`vietjobs_format_sample.csv` – **dữ liệu tự soạn** (tiêu đề có hậu tố "Mẫu", nội dung giả), chỉ mô phỏng đúng
định dạng 18 cột của VietJobs theo file mẫu `data/VietJobs_sample.csv` trong
[VinNLP/VietJobs](https://github.com/VinNLP/VietJobs) (MIT): lương "15.0 - 22.0 triệu", địa điểm viết thường nối
bằng dấu phẩy, cột danh sách dạng chuỗi "['a', 'b']", mô tả nhiều dòng. Không chứa dữ liệu crawl hay dữ liệu cá nhân.
Dòng thứ 5 cố ý thiếu tiêu đề để kiểm tra việc bỏ qua.
